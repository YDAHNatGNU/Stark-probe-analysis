------------------------------------------------------------
2. NOTES ON THE NUMERICAL METHOD
------------------------------------------------------------

The electrostatics is solved as a Fredholm integral equation of the second kind
for the bound surface charge (the boundary-charge, or induced-surface-charge,
formulation). Because the dielectric contrast |lambda| < 1 at every interface,
the system matrix is diagonally dominant and well conditioned - a property
relied on given the near cancellation between interfaces documented in
Supplementary Note 4.

The geometric matrix M depends only on the mesh, so it is assembled once and
cached (asm_cache.py) across the permittivity updates of each self-consistent
solve.


------------------------------------------------------------
3. RUNNING THE PACKAGE ON CODE OCEAN
------------------------------------------------------------

On Code Ocean the package occupies the code folder of the capsule, with the
input data in a data folder inside it, and all outputs are written to the
results folder of the capsule.

run.sh is the entry point. It resolves every location at run time relative to
its own position, sets PYTHONPATH so that the modules in electrostatics can be
imported by one another, links the deposited intermediate files into the
working folder, and then executes the analysis in nine steps. The same script
therefore runs unchanged on Code Ocean or on a local machine. The data location
can be overridden by setting the DATA_DIR environment variable. A complete run
takes 15-25 min on a 2-core machine with 8 GB of memory.

In addition to the raw measurements, the data folder holds four intermediate
files that are inputs rather than outputs of this package:

  ef_data.npy        the Stark fields EF_Local(d) extracted from the
                     linewidths; rebuild_data.py regenerates it from the
                     Source Data linewidth table and confirms it is identical
  halfdecay_mc.json  the measured half-decay distances listed in Table S5.1
                     (Monte Carlo means); the generating script was not
                     preserved, and booth_model.py recomputes the half-decay
                     distances from ef_data.npy by Eq. S5.8 and prints both
  budget4.json       the enhancement budget used by the exclusion test
  run_b.json         the bare-particle reference used by the shell decomposition

The shape pipeline, analyze_tem.py, runs on the three representative
micrographs in data/TEM. The population value of the rounding exponent,
p = 5.5 (IQR 4.6-6.3), used throughout was obtained with the same script on the
full TEM image set.
